# Ranger's Apprentice Extended

Welcome to Ranger's Apprentice Extended!

This is an unofficial fan project featuring original stories, interactive content, character profiles, maps, timelines, and more, inspired by the Ranger's Apprentice series.

## Features
- 📚 Extended fan-made books
- 👥 Character profiles
- 🐴 Horse profiles
- 🗺️ Interactive map
- 🏹 Hidden Rangers
- 🌿 Ranger Points & Oakleaf achievements
